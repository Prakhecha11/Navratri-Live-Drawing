# Navratri Live Drawing 🎨

A Python project that brings a festive Navratri composition to life through an animated drawing and colour-reveal sequence.

## Features

- Animated contour tracing from an image
- Maroon background and golden halo
- Decorative golden frame
- Progressive colour reveal
- Mouse-based golden drawing
- Keyboard controls to clear, save, and exit

## Technologies Used

- Python
- OpenCV
- NumPy

## Requirements

- Python installed on your computer
- OpenCV (`opencv-python`)
- NumPy
- The source image `mataji.jpg`, if permitted for redistribution

## How to Run

1. Install the required packages:

   ```bash
   pip install opencv-python numpy
   ```

2. Keep `navratri_drawing.py` and the required image in the same folder.
3. Run the program:

   ```bash
   python navratri_drawing.py
   ```

## Controls

- **Left mouse button + drag:** Draw in gold
- **C:** Clear added drawings
- **S:** Save the final artwork
- **Q / Esc:** Exit

## Project Purpose

This project explores image processing, contour detection, animation, and interactive drawing using Python and OpenCV.
